# @zcode-dev/plugin-api

Private workspace package (not published to npm). Type definitions for ZCode plugin extensions;
all runtime code lives in `@zcode/shared/extension-host`.

Imported from the upstream 3.18.2 `packages/plugin-api` contract at `fec97590`, rewritten to the
local capability table (the upstream table and sessions/rows projections are not present here yet).
See `NOTICE.md` for the modification statement and the repository's architecture spec
`.agents/specs/upstream-3.18-extension-host-slots.md`.
