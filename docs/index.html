Install

怎么装

准备 Node.js 24.14.0 与 pnpm 10.33.2，在仓库根目录执行即可。

terminal
$pnpm bootstrap# 安装依赖，准备运行资源 $pnpm dev:desktop# 启动桌面应用 $pnpm dev:web# 启动 Web 工作台

不想自己构建？

直接在 GitHub Releases 下载对应平台的桌面安装包：macOS、Windows 与 Linux。安装包未签名，首次打开可能需要在系统中放行。

前往 Releases

命令行版：构建发行包后，zcode 进入终端界面，zcode --web 启动 Web。完整步骤见 README 的初始化一章。
