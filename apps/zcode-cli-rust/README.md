# zcode-cli-rust source landing

This directory contains the mechanically migrated source from `MBearo/ZCode-rs` at commit `06ba9781486cffd395d586ec16138c2eeb5edd58`, with the local M1 protocol implementation retained; the upstream npm launcher is excluded. Current controlled Rust tests report 426 passed and 1 ignored; Linux Node/Rust interop has passed its current alternate, crash-recovery, and different-workspace concurrency cases. The transformation inventory has 70 leaf branches × 5 = 350 leaf cases validating publicNode normalization projection, plus 29 complete Command cases and 1 ACK case validated through `parse_command` + serde outputs. These scoped results are not exhaustive product parity or completion of M2–M8.

The Node driver entry `pnpm test:zcode-cli-rust-drivers` currently has 15 cases; the separate CI script regression suite `node --test --test-isolation=none scripts/ci/*.test.mjs` has 256 cases. Root `pnpm lint` has 51 TypeScript warnings; Rust clippy with `-D warnings` and `cargo fmt --all --check` pass with no warnings / formatting errors. Root `pnpm fmt:check` (oxfmt) has 79 failures, while the scoped task files have no formatting issues.

Do not launch the default runtime. The effective config default must match the current TS CLI storage default (`~/.zcodium`); the shared standalone SQLite session-store fallback uses `.zcodium-exp`, a separate fallback whose mismatch with TS CLI defaults remains an independent decision. Do not migrate user data or claim that Rust defaults universally use `.zcodium-exp`.

Mixed-runtime owner coordination for the same workspace remains unverified. The M8 storage-preparation blocker is in Desktop integration: Rust already implements the command/frames, but Desktop does not declare the capability and rejects `prepareSessionStorage` as `unsupported_runtime` before Rust startup; native process transport is not connected to the Worker branch. Do not add fallback behavior or expand UI/platform interfaces as a workaround. Native Windows/macOS runtime execution has not been performed; native CI compile checks are not runtime evidence. Product acceptance remains pending for browser/CUA, Node REPL, memory, MCP OAuth and other unverified behavior. See [migration spec](../../.agents/specs/cli-rust-runtime.md), [review status](../../.agents/specs/cli-rust-review-status.md), and [CI acceptance contract](../../.agents/specs/cli-rust-ci.md).
