# Visualize resource license

The skill entrypoint, standalone assets, widgets, rendering scripts, and parameter-control runtime are not relicensed under the repository's Apache-2.0 license. This package does not provide an additional license grant for these resources; their existing restrictions continue to apply.

The browser libraries in `assets/vendor/` retain their separate licenses: Floating UI Core and DOM use MIT; Lucide and D3 use ISC. Each library's license text is stored beside its script and recorded in `assets/vendor/manifest.json`.
